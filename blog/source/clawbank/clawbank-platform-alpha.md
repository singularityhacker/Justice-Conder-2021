## ClawBank Platform Differentiators

Earlier ClawBank builds were basically Wise API MCP servers. You could do real bank things with multiple accounts: send money, receive money, convert currencies, etc., but couldn't handle real crypto onramping. To address this, I sourced and signed agreements with several fintech and infrastructure partners and set out to build a foundational structure to support a growing menu of capabilities as partners and features go live.

When you sign up today on the ClawBank platform, you'll be guided through a few simple steps, and you'll have access to:

- Magic link signup (no saved passwords)
- Accelerated KYC (takes 2 mins)
- Dedicated virtual bank account
- Gas-abstracted crypto wallet

After onboarding, you get a virtual account with routing details. Money that hits that account automatically converts to stables in your wallet. You can send from the wallet without worrying about gas.

Once onboarded, you can go to settings, create an API key, and download the MCP built for Claude Desktop. Double-click to install, paste the key when prompted, and then drive your account conversationally. You can still run all the traditional banking functionality by pasting your Wise key into settings. You may need to restart Claude Desktop for the tool list to refresh.

This will be smoother and fully in-platform soon, so don't think this is the final stage. We're just getting started, and launching this platform will unblock a lot of stored momentum.

## ClawBank Roadmap Structure

More capability is already in motion. Several partners from the past 30 days will be rolled out over the coming weeks and months, all under the same theme: capabilities traditionally seen as high-touch and human-centric made fluid and accessible to AI agents.

Some products require their own KYC. We're pushing to keep that to one pass per user, where the law and the vendor allow it. Company formation is far along, with much of it already in testing behind a feature flag. When it goes live, it will simply appear in the app navigation. Each partnership comes with allowed and forbidden use cases and APIs that don't plug together cleanly. ClawBank's job is to unify them under one roof.

We're starting with MCP because it provides a constrained surface for early bug detection. The OpenClaw community gravitates toward a more free-range agent context, so we'll be shipping a ClawBank CLI too.

## First Use Recommendations

The platform has been extensively tested by the private beta group and me, but edge cases may still arise. If you see a bug, please report it using the bug report form. Most issues at this stage are UI or visibility problems, not failures of the underlying system, and I'll address them quickly.
